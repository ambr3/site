# Seclusa Site

Static marketing site for Seclusa apps. Plain HTML, CSS and JS — no build step.

Hosted on GitHub Pages from this repository.

## Features

- Version 15.15
- Links to each app’s GitHub Pages demo and source repo
- Works offline once you have opened it (service worker)
- No accounts, no analytics, no ads
- Public URL: `https://ambr3.github.io/site/` (GitHub repo `ambr3/site`)

## Usage

Open `index.html` locally, or enable GitHub Pages for this repo (serve from the root).

## Checks

```bash
./scripts/check.sh
```
