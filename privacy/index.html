Privacy

Short version: this site does not track you. Apps keep your data on your device unless you choose otherwise.

Updated 2026-11-06

This website

Seclusa is a static site. There are no accounts, no login, no advertising, and no search box that sends queries elsewhere.

I do not run analytics, ad networks, or third-party trackers. There are no third-party scripts, no remote fonts, and pages do not set tracking cookies.

Theme is System, Light, or Dark. System follows this device and is not stored. Light or Dark is saved in localStorage on your device only. A service worker may cache site files so pages work offline. You can clear both from the browser.

The site does not phone home on its own. Links you choose to follow (Open, Source, GitHub, Matrix, email) go to those destinations; this site sends no Referer (Referrer-Policy: no-referrer).

Hosting

The public site is hosted on GitHub Pages. Like any web host, GitHub may process standard request data (such as IP address and user agent) to deliver the site. I do not receive a personal analytics feed from that.

Seclusa apps

Apps are listed on the home page store. Each one is meant to be privacy-first. In general:

  • Notes, Calendar, Blood Pressure, Games and Convert keep data in the browser (local storage / IndexedDB). They do not need an account and are not designed to phone home with your notes, events, readings, scores or conversion prefs.
  • Privacy (the toolkit app) runs entirely on your device: pasted policies, headers and URLs are checked locally and are not designed to be stored or sent anywhere.
  • Weather gets forecasts from Open-Meteo (no API key tied to you). If you allow location, the browser may share coordinates with the weather app so it can request a forecast; you can deny that permission and search by place name instead.

Always check an app’s own README and permissions for the latest details. Source for each app is on GitHub.
